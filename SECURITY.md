# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| latest (`main`) | Yes |

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

To report a vulnerability, email the maintainer directly at **mahmoudalrahbi3@gmail.com** with:

- A description of the vulnerability
- Steps to reproduce it
- The potential impact
- Any suggested fix (optional)

You will receive a response within 48 hours. If the issue is confirmed, a fix will be prioritized and released as soon as possible. You will be credited in the changelog unless you prefer to remain anonymous.
